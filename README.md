# Free AI Research & Decision Workflows for Gemini Notebook (NotebookLM)

3 professional workflows and 10 copy-ready prompts from **The Professional AI Starter Kit** by [NotebookLM Guide](https://notebooklm-guide.com/?utm_source=github&utm_medium=readme&utm_campaign=starter-kit).

Most people use AI as *question → answer*. Professionals work in steps: define the problem, gather evidence, challenge assumptions, then decide. Each workflow below breaks that sequence into prompts you run in order. They work in **Gemini Notebook (formerly NotebookLM)** with your sources loaded, and in ChatGPT, Claude or Gemini when you paste your material in.

## How to use them

1. Pick the one workflow you need today. Each one stands on its own.
2. Run the prompts **in order, in the same chat or notebook**. Each step builds on the one before.
3. Stop where a prompt asks you to approve the framework or confirm the framing. That pause is part of the method.

Every prompt uses the same structure — **Role · Context · Objective · Task · Output format · Quality check** — so you can adapt it to your own work.
